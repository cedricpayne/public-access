How this works

This is a static page with no server. Your browser queries the Internet Archive's search API for video items that describe themselves as public access or community television, then asks the metadata API for each item's derived frame thumbnails and lays those out as a wall of stills.

The curated stations and themes live in data/catalog.json. Each entry is just an Internet Archive search query, so adding a station from your part of the world is a one-line edit.

Untick “Limit to public access & community TV” to search every video on the Archive instead.
